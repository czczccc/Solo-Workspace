# Solo Workspace · 精简 PRD

## 1. 定位

一个人运营三个创业项目的工作台。单用户、移动优先、可安装为 PWA，数据存在自己的服务器上，Windows 桌面与 iPhone 之间实时同步。

**核心问题：** 每天打开就知道 ① 今天做什么 ② 各项目进度如何 ③ 这周完成了什么。

**项目（初始数据）：**

| slug | 名称 | 说明 |
| --- | --- | --- |
| `ai-drama` | AI Drama Overseas | 海外 AI 短剧制作与发布 |
| `ai-science` | AI Science Content | 抖音 AI 科普视频运营 |
| `free-llm-api` | Free LLM API | 免费模型 API 服务 |

## 2. 用户与场景

只有一个用户（我自己）。

| 场景 | 设备 | 期望 |
| --- | --- | --- |
| 早上规划 | iPhone 主屏图标 | 3 秒内看到今日重点，勾掉、标星、调整 |
| 白天执行 | Windows 浏览器 | 看板拖拽，按项目/优先级筛选，编辑子任务 |
| 随手记录 | iPhone | Inbox 一行输入，稍后整理成任务 |
| 周日复盘 | 任意 | 自动汇总本周完成任务，填写收入/成本/复盘 |

## 3. MVP 功能

### 3.1 Dashboard（今日）
- **今日重点**：未完成且（标星“今日重点” 或 截止日 ≤ 今天）的任务；逾期标红；一键完成、取消标星。
- **快速记录**：一行输入直接进 Inbox。
- **本周进度**：本周完成数、进行中、阻塞数；每个项目本周完成/待办与当前里程碑。

### 3.2 Kanban
- 四列：待办 / 进行中 / 阻塞 / 完成。
- 桌面端拖拽换列；移动端按列切换 Tab，卡片菜单改状态。
- 筛选：项目、优先级；卡片显示优先级、截止日期、子任务进度。
- 任务编辑：标题、描述、项目、里程碑、状态、优先级（紧急/高/中/低）、截止日期、今日重点、子任务（增删勾选）。

### 3.3 Projects
- 项目列表：目标、任务完成率、当前里程碑。
- 项目详情：编辑名称/描述/目标/颜色；里程碑增删改与完成；项目任务按状态分组。
- 可新增或归档项目（默认三项）。

### 3.4 Weekly Review
- 以周一为一周开始，可前后翻周。
- 自动列出本周完成的任务（按项目）。
- 每个项目填写：产出、收入、成本；自动汇总利润。
- 复盘：本周亮点、问题与教训、下周重点。
- 历史周报列表。

### 3.5 Inbox
- 快速输入想法（Enter 提交）。
- 一键转为任务（选项目、优先级），或归档、删除。

### 3.6 设置与数据
- 暗色 / 亮色 / 跟随系统。
- JSON 全量导出。
- 数据库备份下载（SQLite 在线备份），并按间隔自动备份到服务器、保留最近 N 份。
- 退出登录。

## 4. 非功能需求

| 项 | 方案 |
| --- | --- |
| 自适应 | 移动端底部导航 + 单列；≥ md 侧边栏 + 多列 |
| iOS 主屏 | Web App Manifest、apple-touch-icon、`apple-mobile-web-app-capable`、safe-area 适配 |
| 离线 | Service Worker 缓存静态资源，离线时显示提示页（写操作需在线） |
| 持久化与同步 | 服务端 SQLite（WAL），所有设备读写同一库；页面为动态渲染 |
| 安全 | 单用户；用户名 + scrypt 密码哈希来自环境变量；HMAC 签名的 httpOnly Cookie；登录失败限流；无注册入口；所有页面、API、Server Action 均校验会话 |
| 部署 | Docker Compose：app + Caddy（自动 HTTPS），数据卷持久化 |

## 5. 不做（明确排除）

AI Agent、团队协作、多用户、聊天、支付、通知推送、第三方集成。

## 6. 验收标准

1. 未登录访问任何页面/API 均跳转登录或返回 401；错误密码多次后被限流。
2. 在桌面创建任务，iPhone 刷新后可见（同一服务器数据库）。
3. 看板可拖拽/切换状态，筛选生效，子任务进度正确。
4. Dashboard 正确显示今日重点与逾期任务、本周完成数。
5. Inbox 想法可转任务并出现在看板。
6. 周报可保存收入/成本/复盘，利润合计正确，自动列出本周完成任务。
7. 主题切换生效且记忆；JSON 导出与数据库备份可下载。
8. iOS Safari “添加到主屏幕”后以独立窗口打开，图标与状态栏正常。
9. `docker compose up -d` 后经 HTTPS 访问。
